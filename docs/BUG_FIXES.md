# 本轮检查与修复

日期：2026-10-07。

| 问题 | 原行为 | 修复与验证 |
| --- | --- | --- |
| 架构识别错误 | 原 ResNet-18 权重被识别为 ResNet-34 | 用完整残差块数和瓶颈结构判断；以真实 torchvision 权重回归 |
| 类别数与权重不完整 | 某些路径默认创建 10 类分类头；加载失败后用 strict=False 继续 | 从权重推断类别数，严格加载；缺失权重或分类头不匹配时停止 |
| 任意模型反序列化 | 上传过程中 weights_only=False 可执行 Python pickle 对象 | 只安全读取权重，不执行 Python 模型对象或 TorchScript；不回退到不安全加载 |
| 虚假评测输入 | CIFAR-10 下载失败悄悄用随机数据；数据集 ID 不存在时改用 CIFAR-10 | 明确报错并保存任务失败原因，保持用户选择的数据来源 |
| 扰动单位不一致 | 归一化后的图像直接送给按 0–1 裁剪的攻击 | 原始像素进入攻击，标准化移入模型；验证像素 eps 上限和单样本批次 |
| 任务阻塞网页 | async 后台函数内部执行长时间同步计算 | 同步线程池后台任务，顺序执行；评测期间状态接口仍响应 |
| 资源访问越权 | 模型配置未检查拥有者，启动任务未检查数据集拥有者，管理接口未要求管理员 | 所有私有资源检查用户身份；管理员接口与普通用户个人资料分离 |
| 禁用账号仍可访问 | 登录与已发出的 token 未重新检查账号状态 | 登录拒绝停用 / 删除账号，已有会话每次请求也检查当前账号与角色 |
| 密码重置未生效 | 重置接口只返回成功；新增用户存明文密码 | 新增和重置写入 bcrypt，重置撤销旧会话，验证新密码可登录 |
| 个人资料路由冲突 | 重复的认证 / 资料路由，动态用户 ID 路由可先匹配静态路径 | 合并资料处理，静态路径先注册，验证普通用户可读自己的资料 |
| 单类别 ZIP 被破坏 | 无条件拆掉唯一目录，使类别目录消失 | 区分类别目录和外层包装，测试两类结构与大写 ZIP 后缀 |
| 无界 ZIP 解压 | 无上传上限、展开上限和显式路径检查 | 限制大小和文件数，拒绝越界与链接，错误清理仅针对生成的目录 |
| 私有数据公开下载 | /uploads 静态服务能暴露模型、任务和元数据 | 仅公开经重编码的头像；模型及元数据经过认证接口 |
| 数据库配置无法迁移 | 代码内写死 MySQL 凭据，依赖清单缺 SQLAlchemy / bcrypt | 默认本地 SQLite，可配置 MySQL；交互设置管理员密码，补全依赖 |
| 中断任务和元数据写入 | 服务重启后任务永远运行；直接覆盖 JSON 可能留下半写文件 | 重启将未完成任务标为中断；JSON 临时写入后原子替换 |
| 未实现管理操作报告成功 | 角色、部门和菜单编辑接口没有实际更新 | 返回明确的 501 待实现提示，并在 README 记录范围 |
| 前端异常处理 | 上传 FormData 被按空 JSON 判为重复；HTTP 错误只显示状态码，轮询失败不停止 | 文件上传跳过该判断，展示后端错误，查询失败停止轮询并引导重试 |
| 前端构建死循环 | Webpack 4 的哈希模块编号在重复标识下无限循环，构建卡住 | 移除旧哈希编号插件，采用数字模块编号；保留资源文件哈希，生产构建通过 |
| 登录保存可恢复的密码 | 预填通用密码；把密码用前端内置密钥加密存入 Cookie | 初始密码留空，只记住账号，清理旧密码 Cookie，移除无用的内置密钥工具 |
| 首页与业务不一致 | 展示框架演示、捐赠和 Java 技术栈，实际后端为 Python | 首页提供模型、评测、任务入口与复现要点；保留上游许可和 README 鸣谢 |
| 缓存评测页保留旧模型列表 | 先打开评测再上传模型，从模型页跳回评测时不刷新，也不应用新的 modelId | 页签激活时刷新资源列表，监听路由参数并带入目标模型；通过真实网页上传与跳转验证 |
| 缓存任务页看不到新任务 | 初次打开时没有运行任务，切页创建新任务后回到原页仍显示旧列表 | 激活时重新查询并启动唯一轮询器，离开页签时停止列表轮询 |
| HTTP 401 无重新登录入口 | 后端返回真正的 HTTP 401，前端只对 JSON code=401 处理重新登录 | 两种响应统一给出重新登录入口；先清理本地 token，避免再次请求失效会话 |
| 新机器无法按锁定依赖安装 | 上游忽略规则排除了 package-lock.json，npm ci 无法运行 | 将锁文件纳入版本控制；用 GitHub 的全新环境验证安装与生产构建 |

原版本的两个行为已用独立探针复现：ResNet-18 返回 resnet34；模拟下载失败后返回 10 个随机样本。修复版的测试采用临时数据库、临时图像及小模型，不读取或更改原有用户数据。

本轮未训练新的大型模型或跑完整 CIFAR-10 基准。测试中的小型真实图像评测仅验证流程和指标计算，不作为真实模型性能结果。
